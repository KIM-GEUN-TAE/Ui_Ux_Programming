# 겜뽑기

취향만 고르면 오늘 할 게임을 뽑아드립니다.

- 배포 주소: https://kim-geun-tae.github.io/Ui_Ux_Programming/
- 저장소: https://github.com/KIM-GEUN-TAE/Ui_Ux_Programming

## 프로젝트 소개

| 항목 | 내용 |
| --- | --- |
| 서비스 | 취향 조건에 맞는 게임 중 하나를 추첨해 오늘 할 게임을 정해 주는 웹페이지 |
| 사용자 | 게임은 많은데 오늘 뭘 할지 정하지 못해 시간을 보내는 게이머 |
| 서비스 목적 | 내 취향에 맞는 게임을 고민 없이 빠르게 하나 정한다 |
| 핵심 행동 | 취향 키워드를 입력하고 인원 · 플레이 시간을 고른 뒤 게임을 뽑는다 |
| 완료 조건 | 확인 단계에서 입력 · 선택한 조건과 후보 수를 검토하고, 뽑기 완료 화면에서 오늘의 게임을 확인한다 |

## 사용자 흐름

시작 → 입력 → 선택 → 확인 → 완료

1. 시작: 게임 뽑기 영역에서 "게임 뽑기 시작하기"를 누른다.
2. 입력: 분위기 · 장르 키워드를 쉼표로 이어 입력한다. 비어 있거나 키워드가 모두 들어간 게임이 없으면 같은 단계에서 고친다.
3. 선택: 함께 할 인원(필수)과 플레이 시간을 고른다. 인원을 "함께"로 고르면 친구와 같은 기기에서 할 수 있는지 확인하라는 안내가 나타난다.
4. 확인: 키워드 · 인원 · 플레이 시간과 후보 수를 검토한다. 틀린 값은 이전 단계로 돌아가 고친다.
5. 완료: 오늘의 게임을 확인하고, 같은 조건으로 다시 뽑거나 "처음부터 다시 하기"로 입력 단계부터 다시 시작한다.

뽑기 설정에서 입력한 닉네임은 결과 문구 앞에 붙고, "취향 키워드 없이 뽑기"를 선택하면 입력 단계에서 키워드 없이 다음 단계로 넘어간다.

## 인터랙션 시나리오

| 행동 | 이벤트 | 조건 | 화면 반응 | 다음 상태 |
| --- | --- | --- | --- | --- |
| "게임 뽑기 시작하기" 클릭 | click | 없음 | 시작 버튼이 사라지고 진행 표시 `1 / 3 · 취향 입력`과 키워드 입력창이 나타나며, 입력창에 커서가 놓임 | 입력 단계 |
| 키워드 없이 "인원·시간 고르기" 클릭 | submit | 키워드가 비어 있음 | 입력창에 빨간 테두리, "취향 키워드를 입력해 주세요. (예: 힐링, RPG)" 안내 | 입력 단계에 머묾 |
| "공포, 협동" 입력 후 다음 | submit | 키워드가 모두 들어간 게임이 0개 | 키워드를 줄이거나 취향 고르기 탭에 있는 키워드로 바꾸라는 안내 | 입력 단계에 머묾 |
| 맞는 키워드 입력 후 다음 | submit | 후보가 1개 이상 | 오류 안내가 처음 안내 문구로 돌아가고 `2 / 3 · 인원·시간 선택` 표시 | 선택 단계 |
| 인원을 고르지 않고 "선택 내용 확인하기" 클릭 | click | 인원이 비어 있음 | 인원 선택창에 빨간 테두리, "함께 할 인원을 선택해 주세요." 안내 | 선택 단계에 머묾 |
| 인원 변경 | change | 선택값이 바뀜 | 선택 단계의 오류 안내가 지워지고, "함께"이면 같은 기기 확인 안내가 나타남 (다른 값이면 숨김) | 선택 단계 유지 |
| "공포" + "함께"로 확인 | click | 조건에 맞는 게임이 0개 | 플레이 시간을 바꾸거나 이전 단계에서 키워드를 수정하라는 안내 | 선택 단계에 머묾 |
| "키워드 수정하기" 클릭 | click | 없음 | 입력한 키워드가 그대로 남은 입력 단계 표시 | 입력 단계 |
| 확인 단계에서 "인원·시간 수정하기" 클릭 | click | 없음 | 고른 인원 · 시간이 그대로 남은 선택 단계 표시, 고친 뒤 다시 확인하면 요약에 바뀐 값이 반영됨 | 선택 단계 |
| "이 조건으로 게임 뽑기" 클릭 | click | 없음 | 진행 표시 `뽑기 완료`, 초록 상자에 "오늘의 게임은 「게임 이름」입니다!" | 완료 |
| "같은 조건으로 다시 뽑기" 클릭 | click | 없음 | 확인한 후보 중에서 새로 뽑은 결과 표시 | 완료 유지 |
| "처음부터 다시 하기" 클릭 | click | 없음 | 키워드 · 인원 · 시간 · 오류 · 안내 · 요약 · 결과와 "취향 키워드 없이 뽑기" 체크를 처음 상태로 돌리고 `1 / 3 · 취향 입력` 표시 | 입력 단계 |
| 뽑기 설정의 "취향 키워드 없이 뽑기" 체크 | change | 체크됨 | 키워드 입력창이 비활성화되고 안내가 "취향 키워드 없이 인원·플레이 시간만으로 뽑습니다."로 바뀜 | 입력 단계에서 키워드 없이 다음으로 이동 가능 |

## 테스트 결과

| 구분 | 조작 | 결과 |
| --- | --- | --- |
| 정상 | 시작 → "힐링" 입력 → 혼자 · 짧게 → 확인 → 게임 뽑기 | 확인 화면에 "키워드: 힐링 · 인원: 혼자 · 플레이 시간: 짧게 → 조건에 맞는 게임 4개 중에서 뽑습니다."가 표시되고, 완료 화면에 후보 4개 중 한 게임이 표시됨 |
| 빈 입력 | 키워드 없이 다음 / 인원을 고르지 않고 확인 | 각 단계에 머물고 빨간 테두리와 수정 방법 안내가 나타남 |
| 맞는 게임 없음 | "공포, 협동" 입력 / "공포" + "함께" 선택 | 다음 단계로 넘어가지 않고 키워드나 조건을 바꾸라는 안내가 나타남 |
| 이전 · 수정 | 확인 → "인원·시간 수정하기" → 시간을 보통으로 변경 → 다시 확인 | 혼자 · 짧게가 그대로 남아 있고, 확인 화면에 "보통"과 후보 3개가 반영됨 |
| 완료 | "이 조건으로 게임 뽑기" 후 "같은 조건으로 다시 뽑기" 20회 | `뽑기 완료`가 표시되고, 결과는 항상 확인한 후보 안의 게임 |
| 다시 시작 | 오류 · 안내 · 결과가 보이는 상태, "취향 키워드 없이 뽑기"를 체크한 상태에서 각각 "처음부터 다시 하기" | 키워드 · 인원 · 시간 · 오류 · 안내 · 요약 · 결과 · 진행 표시와 "취향 키워드 없이 뽑기" 체크가 모두 처음 상태로 돌아감 (뽑기 설정의 닉네임은 유지) |
| 키보드 | Enter로 키워드 제출, Enter · Space로 다음 단계와 다시 뽑기 | 단계가 바뀌면 다음에 조작할 입력창이나 버튼으로 포커스가 이동함 (키워드 없이 뽑기를 켜면 1단계에서는 "인원·시간 고르기" 버튼으로 이동) |
| 모바일 | 390px · 768px에서 모든 단계 조작 | 레이블 · 입력창 · 버튼 · 오류 안내가 잘리지 않고 가로 스크롤 없음, 버튼은 한 줄에 하나씩 배치됨 |
| 기존 기능 | 주요 기능 탭, 화면 테마, 닉네임 글자 수, 키워드 없이 뽑기 | 이전과 같이 동작함 |
