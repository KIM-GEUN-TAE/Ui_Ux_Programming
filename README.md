# 겜뽑기

취향만 고르면 오늘 할 게임을 뽑아드립니다.

- 배포 주소: https://kim-geun-tae.github.io/Ui_Ux_Programming/
- 저장소: https://github.com/KIM-GEUN-TAE/Ui_Ux_Programming

## 프로젝트 소개

| 항목 | 내용 |
| --- | --- |
| 서비스 | 취향 조건에 맞는 게임 중 하나를 추첨해 오늘 할 게임을 정해 주는 웹페이지 |
| 사용자 | 게임은 많은데 오늘 뭘 할지 정하지 못해 시간을 보내는 게이머 |
| 서비스 목적 | 내 취향에 맞는 게임을 고민 없이 빠르게 하나 정한다 |
| 핵심 행동 | 취향 키워드를 입력하고 인원 · 플레이 시간을 고른 뒤 게임을 뽑는다 |
| 완료 조건 | 확인 단계에서 입력 · 선택한 조건과 후보 수를 검토하고, 뽑기 완료 화면에서 오늘의 게임을 확인한다 |

## 사용자 흐름 (7주차)

시작 → 입력 → 선택 → 확인 → 완료

1. 시작: 게임 뽑기 영역에서 "게임 뽑기 시작하기"를 누른다.
2. 입력: 분위기 · 장르 키워드를 쉼표로 이어 입력한다. 비어 있거나 키워드가 모두 들어간 게임이 없으면 같은 단계에서 고친다.
3. 선택: 함께 할 인원(필수)과 플레이 시간을 고른다. 인원을 "함께"로 고르면 친구와 같은 기기에서 할 수 있는지 확인하라는 안내가 나타난다.
4. 확인: 키워드 · 인원 · 플레이 시간과 후보 수를 검토한다. 틀린 값은 이전 단계로 돌아가 고친다.
5. 완료: 오늘의 게임을 확인하고, 같은 조건으로 다시 뽑거나 "처음부터 다시 하기"로 입력 단계부터 다시 시작한다.

뽑기 설정에서 입력한 닉네임은 결과 문구 앞에 붙고, "취향 키워드 없이 뽑기"를 선택하면 입력 단계에서 키워드 없이 다음 단계로 넘어간다.

## 중간고사 · 새로 추가한 기능: 뽑은 게임 기록

7주차 흐름은 오늘의 게임을 뽑는 데서 끝났다. 중간고사에서는 완료 화면에 "이 게임 기록하기"를 추가해, 뽑은 게임에 별점(1~5점)과 한 줄 메모를 남기고 새 영역 "내 게임 기록"에서 모아 보고 고치고 지울 수 있게 했다.

- 연결 지점: 7주차 흐름의 끝(완료 단계)에서 기록 단계로 이어지고, 저장하거나 취소하면 다시 완료 단계로 돌아온다.
- 7주차와 다른 점: 7주차는 입력한 값으로 한 번 뽑고 끝났지만, 이번 기능은 입력한 별점 · 메모를 기록으로 쌓아 두고(추가 · 고치기 · 삭제), 쌓인 기록을 다음 뽑기 결과에 다시 보여 준다. 완료 화면 버튼의 click, 기록 입력의 submit, 별점 선택의 change, 메모 입력의 input 이벤트로 조건을 검사한다.
- 사용자 목표와의 연결: 해 본 게임의 평가를 남겨 두면, 다시 뽑다가 같은 게임이 나왔을 때 지난번 별점이 함께 보여 바로 할지 다시 뽑을지 고민 없이 정할 수 있다.
- 중간 프로토타입이라 기록은 페이지를 연 동안만 유지되며, 새로고침하면 처음 상태로 돌아간다.

시작 → 입력 → 선택 → 확인 → 완료 → **기록 (새로 추가)** → 완료

### 사용자 행동 · 조건 · 반응

| 사용자 행동 | 확인할 조건 | 화면 반응 | 다음 행동 |
| --- | --- | --- | --- |
| 완료 화면에서 "이 게임 기록하기" 클릭 | 이 게임이 이미 기록에 있는지 | 진행 표시가 `게임 기록`으로 바뀌고, 기록할 게임 이름과 별점 · 한 줄 메모 입력칸이 나타나며 첫 별점에 포커스. 이미 기록한 게임이면 저장된 별점 · 메모가 채워지고, 저장된 별점에 포커스, 버튼이 "기록 고치기"로 바뀜 | 별점을 고르고 저장 |
| 별점을 고르지 않고 "기록 저장하기" (오류) | 별점을 골랐는지 | 기록 단계에 머물고 별점 묶음에 빨간 테두리, "별점을 1점부터 5점 중에서 하나 골라 주세요." | 별점을 고르면 안내가 지워지고, 다시 저장 |
| 메모를 30자 넘게 적고 저장 (오류) | 메모가 30자 이내인지 | 기록 단계에 머물고 메모칸에 빨간 테두리, "한 줄 메모가 N자입니다. 30자 이내로 줄여 주세요." (고른 별점은 유지) | 메모를 30자 이내로 줄이면 안내가 지워지고, 다시 저장 |
| 별점(+ 메모) 입력 후 저장 (성공) | 처음 기록하는 게임 | 완료 화면으로 돌아와 초록 안내 "「게임」 기록을 저장했습니다. (별점 N점)", 내 게임 기록 끝에 카드가 추가되고 개수가 바뀜, 버튼은 "이 게임 기록 고치기"로 바뀜 | 같은 조건으로 다시 뽑기, 내 게임 기록 확인 |
| 이미 기록한 게임을 고쳐 저장 (수정) | 이미 기록에 있음 | "「게임」 기록을 별점 N점으로 고쳤습니다." 기록 개수는 그대로이고 해당 카드의 별점 · 메모만 바뀜 | 같은 조건으로 다시 뽑기 |
| "기록하지 않고 돌아가기" (취소) | 저장된 기록이 있는지 | 입력하던 값을 버리고 완료 화면으로 돌아감. 새 게임이면 "기록하지 않았습니다…", 고치던 게임이면 "기록을 고치지 않았습니다. 저장된 별점 N점이 그대로 남아 있습니다." | 다시 기록하거나 다시 뽑기 |
| "같은 조건으로 다시 뽑기" | 새로 뽑힌 게임이 기록에 있는지 | 기록한 게임이면 "지난번에 별점 N점으로 기록한 게임입니다." 안내와 "이 게임 기록 고치기", 아니면 안내 숨김 | 바로 플레이하거나 다시 뽑기 |
| 내 게임 기록에서 "기록 삭제" | 남은 기록이 있는지 | "「게임」 기록을 삭제했습니다. 남은 기록 N개", 남은 기록이 없으면 결과 없음 안내로 바뀜 | 남은 기록 확인 또는 게임 뽑으러 가기 |
| 기록이 하나도 없을 때 (결과 없음) | 기록 개수가 0개인지 | "아직 기록한 게임이 없습니다…" 안내와 "게임 뽑으러 가기" 버튼 | 버튼을 눌러 게임 뽑기 영역으로 이동 |
| "처음부터 다시 하기" | 없음 | 7주차의 초기화에 더해 기록 입력칸과 완료 화면의 기록 안내도 비움. 이미 저장한 기록은 유지 | 입력 단계부터 다시 뽑기 |

| 결과 없음 · 삭제 | 처음 접속 / 기록 2개를 하나씩 삭제 | 처음에는 결과 없음 안내와 "게임 뽑으러 가기"(누르면 게임 뽑기 영역으로 이동). 삭제할 때마다 남은 개수 안내, 마지막 기록을 지우면 결과 없음 안내로 돌아감 |

| 키보드 | 별점에서 방향키, 메모칸에서 Enter | 방향키로 별점이 바뀌고 Enter로 저장됨. 단계가 바뀌면 다음에 조작할 별점 · 버튼으로 포커스 이동 |
